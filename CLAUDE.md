# Fable Method Workflow (Think / Act / Prove)

- **Think & Plan**: Before any non-trivial multi-step task, apply the `fable-method` loop (`/fable-method` or `/fable-loop`). Classify the ask before touching anything, define done with named verification, gather evidence in parallel from primary sources, and commit to one recommendation.
- **Act Surgically**: Execute tasks by gathering evidence first, writing the `INTENT:` statement when changing behavior, and making the smallest correct change.
- **Prove & Verify**: After completing substantive work, or whenever any agent/tool claims work is done, run a `fable-judge` pass before presenting it as finished. "Did that actually work?" = `fable-judge`.
- **Honest Reporting**: Report outcomes first with honest caveats.
